# سلبود (Silbood) — منصة تحفيز الطلاب

## نظرة عامة
موقع تحفيزي لطلاب الصف التاسع — يحل الطالب الواجبات، يرفع صور الحل (2 على الأقل)، ويجمع نقاطاً تُستبدل بمال حقيقي.

## التقنية
- **ملف واحد:** `index.html` — يحتوي HTML + CSS + JavaScript
- **React 18** (من CDN)
- **Tailwind CSS** (من CDN)
- **Babel** (تحويل JSX بالمتصفح)
- **Jitsi Meet** (غرف الصوت)
- **تخزين محلي:** localStorage (البيانات) + sessionStorage (الجلسة)

## الميزات
| الميزة | الوصف |
|--------|-------|
| الحل الفردي | 20 نقطة — يرفع صورتين على الأقل |
| الحل الجماعي | 10 نقاط — كل عضو يرفع صورته |
| الحد اليومي | 3 واجبات كحد أقصى |
| الاستبدال | 500 نقطة = 30 قرشاً |
| الغرف | عام أو خاص (بدعوة/رابط) |
| الفحص العشوائي | 10% — فيديو شرح 15 ثانية (يُحذف بعد 24 ساعة) |
| الأوسمة | برونزي 500 / فضي 1500 / ذهبي 3000 |
| المزامنة | فورية بين التابات (بدون ريفرش) |
| الشروط | 18 شرطاً + توقيع ولي الأمر |

## بيانات الدخول
- **طالب:** `salim` / `1234`
- **مشرف:** `rayed` / `RAED2026`

## التشغيل
1. افتح `index.html` بأي متصفح
2. أو شغّل سيرفر محلي: `python -m http.server 8137`
3. افتح `http://localhost:8137`
